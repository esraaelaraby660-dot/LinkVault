Libraries
1. **react-router-dom**: Handle navigation and routing between pages(Home, Login, Register, ResetPassword,OTP, ForgetPassword)

2. **tailwindcss**: Used to  style components and layouts with utility classes , @theme design tokens and custom css variables (:root , .dark)

3. **axios** : Used in API operation (GET, POST , PUT , DELETE)
4. **zustand**: Used to make global state
5. **formik**: Manages form state, values, and submission handling.
6. **yup**: Defines validation schemas for form inputs.
7. **react-icons**: Provides scalable vector icons across the UI.
